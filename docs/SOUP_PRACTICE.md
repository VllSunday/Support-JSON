# Soup и учебная практика

Soup организует эксперимент поверх Transformers/PEFT/TRL и, при выборе соответствующего backend, Unsloth. Это полезно для воспроизводимых запусков. Автоматические настройки не гарантируют качества нашей модели или корректной постановки эксперимента.

В первом эксперименте используем явный YAML и отключаем autopilot, случайное разделение, packing и layer streaming. Основные настройки:

| Параметр | Выбор | Что нужно понять |
|---|---|---|
| LoRA rank / alpha | 16 / 32 | Какие дополнительные матрицы обучаются и как масштабируется их вклад |
| Квантизация обучения | none | Основные веса загружаются без INT4; обучение адаптера не равно полному fine-tuning |
| Loss | только assistant | Правила и обращение доступны модели, но их токены не должны быть целевым ответом |
| Эффективный batch | 1 × 8 accumulation | Когда обновляются параметры и как накопление влияет на память |
| Длина | 2048 токенов | Почему обрезанный контекст способен разрушить разметку; все фактические ответы пилота проверены |
| Epochs / learning rate | 1 / 1e-4 | Это стартовые значения, выбираемые по validation, а не доказанно оптимальные |

Перед полным обучением выводим реальные trainable parameters, фактический dtype и выбранные target modules; проверяем маски loss на одном токенизированном примере и память на одном батче. `target_modules: all-linear` для текстового декодера должно быть подтверждено фактическим списком. Само принятие YAML ничего из этого не доказывает.

У Soup 0.75.0 нет отдельного поля validation file в DataConfig. Мы ставим val_split=0 и оцениваем собственную validation отдельно; validation loss внутри trainer в этой конфигурации отсутствует. Тестовый файл никогда не передаётся train.

Важно понимать путь данных: исходная запись → system/user/assistant → chat template → токены и маски → frozen base + LoRA → loss → обновление адаптера → генерация → наши метрики. Для защиты сохранение и объяснение этих промежуточных результатов полезнее ручного переписывания всей инфраструктуры.

Документация инструмента:

- [Поддержка моделей и текстовый режим](https://github.com/MakazhanAlpamys/Soup/blob/main/docs/models.md)

Из установленного пакета проверена версия 0.75.0. Документация main может меняться. Совместимость GPU, маска всех 192 примеров, полный запуск из 24 шагов и сохранение адаптера проверены. Windows-окружение использует FLA/Triton Windows и Liger; проверка GPU-ядер описана в FIRST_RUN.md. Публикация и перенос на другой компьютер не подтверждены. Для публичной модели сохраняем версии библиотек, ревизию исходных весов и инструкцию запуска.
