# Интерфейс первого прототипа

Пользователь — оператор поддержки. Его задача: проверить предложение модели
по обращению и действующим правилам компании. Главное действие — «Разобрать
обращение». Результат не исполняет возвраты, отмены или изменения аккаунта.

Композиция: рабочий лист с обращением и правилами слева, решением и ответом
справа. Правила редактируются прямо рядом с обращением: это показывает
механизм адаптации к компании, а не обещает универсальность модели.
На узком экране панели идут последовательно. Всё выровнено по левому краю.

Цвета: бумага #ffffff, фон #eef3f7, чернила #182b3b, вторичный #526575,
синий #245b85, предупреждение #8a4e0a. Шрифт Segoe UI для русского текста;
Consolas только для JSON. Акцент — связь решения с применёнными правилами.
Карточки одинакового размера, рекламные метрики и декоративные графики здесь
не помогают рабочей задаче и не используются.

Проверка плана: обычная форма без доверенного контекста скрыла бы механизм
Support-JSON. Поэтому правила и факты остаются видимыми, а сырое предсказание
можно раскрыть. Загрузка, пустой результат и ошибки дают конкретное действие.
