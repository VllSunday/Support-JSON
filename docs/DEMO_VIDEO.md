# Презентационное видео

`assets/demo.mp4`: 35 секунд, 1600×900, 24 fps, H.264, без звука. GIF в README — уменьшенная версия того же монтажа.

Четыре исходных кадра в `assets/demo-captures/` сняты через браузер с настоящего локального приложения и выбранной LoRA. Это не макет и не подставленный ответ. Убрано только внешнее пустое поле снимка; приложение не перерисовывалось. Добавлены титры, переходы и плавное приближение.

Показан известный validation-сценарий: раздражённый клиент просит документ по оплате; система подтверждает наличие счёта. Правила задают low независимо от тона и разрешают предложить скачивание. Реальная модель вернула billing / low / negative / propose_action / propose_invoice_download, ссылки на два правила и черновик. JSON открыт и скопирован через интерфейс.

Прогон занял 23,87 секунды, включая ленивую загрузку модели. Ожидание сокращено монтажом; видео не является замером скорости или новым независимым бенчмарком. Приложение предлагает действие, не исполняет его. Ответ должен проверить оператор.

Для воспроизведения монтажа на Windows установите Pillow и imageio-ffmpeg в отдельное окружение, затем запустите `python scripts/build_demo_video.py`. Используются системные шрифты Segoe UI; сборка выполняется на CPU. Хеши источников и полная проверка декодирования находятся в `reports/demo-video.json`.
