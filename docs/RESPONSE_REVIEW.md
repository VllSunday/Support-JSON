# Содержательная оценка ответов

Автоматическая проверка JSON, действия и ссылок на правила не измеряет правдивость всего текста. Поэтому после фиксации адаптера и завершения test отдельно оцениваем ответы на 36 ситуациях: по одному случайному эмоциональному варианту каждой из девяти семей и четырёх состояний. Это покрывает разные задачи и сложности, но не является случайной выборкой реального потока компании.

`scripts/prepare_response_review.py` создаёт пары A/B со случайным порядком. Оценщик видит сообщение, правила, происхождение фактов и два необработанных ответа. Название модели скрыто в отдельном mapping. Настройки и модель после этой оценки не меняются; иначе test перестал бы быть независимым.

Рубрика response quality (1–5):

- 5: правильное решение по данным и правилам, понятный вежливый ответ, нужное уточнение или эскалация, отсутствие лишних обещаний.
- 4: правильное решение, небольшая стилистическая неточность или недостаточная конкретность без нового фактического утверждения.
- 3: частично полезный ответ, существенное упущение или неясность; оператору нужна заметная правка.
- 2: неверное решение или существенное противоречие правилу, требующее переработки.
- 1: нет пригодного ответа, копия схемы, неправильный формат без извлекаемого ответа либо опасное неподтверждённое исполнение операции.

Hallucination = true, если текст утверждает неподтверждённый факт, выполненную операцию, обещанный срок либо доступную возможность, отсутствующую в контексте или противоречащую правилам. Неправильный приоритет или JSON сам по себе не считается галлюцинацией текста. Если пригодного reply нет, hallucination=null («не оценимо»), response quality=1. Долю галлюцинаций считаем только среди оценимых ответов, отдельно показываем число неоценимых. Нулевой показатель не доказывает отсутствие ошибок на других данных.

В capstone допускается AI-assisted аудит автором-ассистентом, но он явно отделяется от независимой человеческой разметки. `human_evaluation` остаётся null до настоящего человеческого ревью. Сводка AI-assisted сохраняет метод, выборку, оценки, короткие обоснования и знаменатели; её нельзя называть независимым human benchmark.

Для публикации желательна проверка другим человеком и более широкий набор естественных переписок. Часть качественных ошибок классификации действий не является фактической галлюцинацией; показатели выводятся отдельно.
