Обращение и контекст

Правила и контекст передаются модели вместе с каждым обращением.

Синтетический пример

Вымышленные обращения без персональных данных. Текст можно править вручную.

Измените текст правила и разберите обращение заново, чтобы сравнить решение.

6 правил
Факты 5
    слова клиента

    Со слов клиента, системой не подтверждено.

    система

    Наблюдение сервиса. Значение null означает, что факт неизвестен.

    Редактировать факты в JSON

    origin: user_report — слова клиента; tool_observation — данные системы. Неизвестный факт: null.

    История переписки 2

      История относится к текущему обращению. При изменении текста прежние факты и история сбрасываются.

      Редактировать историю в JSON

      role: user или assistant. История не подтверждает факты из системы.

      Готово к разбору. Первый запрос может включать загрузку модели.

      Предложение оператору

      Проверьте ответ перед отправкой клиенту. Возвраты, отмены и изменения аккаунта выполняет оператор — приложение их только предлагает.

      Решение устарело

      Входные данные изменились после разбора. Копирование черновика отключено — нажмите «Разобрать обращение», чтобы получить актуальное решение.

      Разбор не выполнен

      Что сделать: проверьте входные данные. Если ошибка повторяется, изучите журнал сервера или передайте обращение оператору. Невалидный ответ не используется как черновик.
